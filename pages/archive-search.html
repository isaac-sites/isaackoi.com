AFU Magazine Search

Search the United States magazine PDFs in the AFU online archive. The files are hosted by Archives for the Unexplained; this search interface and index were prepared by Isaac Koi.

This test page currently embeds the working AFU-hosted search interface while cross-origin access for a fully native isaackoi.com interface is being checked.

If the embedded search does not load, open it directly at files.afu.se/Downloads/search/.
